# Routes and mandate

Read project agent instructions and any workflow file (default
`docs/agents/workflow.md`). Existing paths and caller executor policy win;
infer missing conventions from the checkout. Setup is optional.

Choose only the activity the request needs. Investigate uncertain value;
clarify consequential intent; save settled scope; assign independent units
only when useful; implement a selected unit or the whole specified outcome.
Named skills are optional aids, not prerequisites or mandatory consecutive gates.
A clear bug needs no spec or tickets; a local spec needs no tracker or plan.

Preserve the caller's mandate. Discussion, research, drafting and review do not
authorize production implementation or external publication. Adequately scoped
implementation authorizes routine local planning and technical decisions.
Ask for missing intent or a changed mandate, not repeated technical approvals.
External writes require user authorization or explicit caller policy; prepare
reviewable drafts first when publication authority is missing.

Persist findings when future use warrants it. Discovery can continue, defer,
abandon or answer without implementation. Abandonment may retain evidence,
rationale and a reconsideration condition; it creates no implementation assignment.
